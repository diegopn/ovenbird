# Ovenbird screenshots

This directory contains the two selected screenshots in `processed/`:

- `ovenbird-editor.png`
- `ovenbird-references.png`

Both are 1480 × 949 pixel RGBA PNG images. The wallpaper and outer window shadow
have been removed, preserving the interface and transparent rounded corners.

The MetaInfo references these existing images through the exact commit used for
the stable `v0.2.0` release, so the image URLs remain fixed even if a tag changes.
