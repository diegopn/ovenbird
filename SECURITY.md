# Security Policy

## Supported Versions

Security fixes are prepared for the latest stable release. Older releases may not receive backported fixes; please update to the latest stable version before reporting an issue.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

If private vulnerability reporting is available for this repository, submit a report through [GitHub's private vulnerability reporting form](https://github.com/diegopn/ovenbird/security/advisories/new). You can also find it under **Security → Advisories → Report a vulnerability**. GitHub only provides this form when the repository has private vulnerability reporting enabled.

If the form is unavailable, use the [project contact page](https://diegopn.github.io/) to request a private channel. Do not include exploit details, sensitive files, or personal data in that initial message.

Please include the affected Ovenbird version, operating system and installation source (such as Flathub or a native build), steps to reproduce the issue, and its possible impact. Redact logs and examples to remove personal documents, bibliography data, credentials, and other private information.

## Disclosure

The maintainers will acknowledge and assess reports as soon as practical. There is no guaranteed response or remediation timeline. For confirmed vulnerabilities, the maintainers will coordinate with the reporter on a fix and public disclosure. Please do not publish vulnerability details before the fix is available or another disclosure date has been agreed upon.
